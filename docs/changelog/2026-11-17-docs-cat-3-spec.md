  ([spec](../specs/cat-3-movement-library.md); `CAT-3`, decided by the maintainer). The app will get

  rewritten to answer them, and the roadmap edits; it also takes personal names out of one source
  file's comments in the working tree (they remain in the history). No behaviour changes yet.
