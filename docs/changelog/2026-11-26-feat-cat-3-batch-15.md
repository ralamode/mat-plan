# Catalog batch 15: 39 movements for splits, stance holds, grip and core

CAT-3: the library gains 39 movements a family's programs used and the 587 did not have. They cover
split and straddle stretches, controlled leg raises, wrestling stance holds and stance-start drills,
grip work, and the easier and harder steps of the core exercises (band chop and lift, incline plank,
ball rollout, tuck L-sit). Each is written in-house and approved row by row before it merges; the
next `migrate.yml` seed adds them to production, since the seed inserts any catalog movement it does
not already hold.
