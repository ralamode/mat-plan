- **2026-10-07** — **Sentry 11, with what it collects set explicitly** (#257). The major removed `sendDefaultPii` and replaced it with `dataCollection`, whose every field defaults to **on**: request bodies (a Server Action's body is its form, so a weight or the access code), headers, cookies, DB query data, stack-frame locals and AI prompts. Taking the bump as-is would have widened what reaches Sentry. `SENTRY_DATA_COLLECTION` (`apps/web/lib/sentry-scrub.ts`) turns every field off, and its `Required<…>` type makes a future SDK field a compile error until someone decides it. Both runtime configs pass it, a test pins that wiring, and the scrubber now also strips request bodies and frame locals as a second line. `withSentryConfig` moved to `@sentry/nextjs/config`.
