- **2026-11-19** — **FAM-1 12d-iii: on the day page, the reps of a set logged in another unit can be changed in place.**
  When a workout's unit was edited after a set was logged (a set in pounds, the workout now in
  kilograms), Change now offers that set's reps. The load stays as it was logged, shown in its own
  unit and sent back unchanged, so no load is ever stored in the wrong unit (D44, Form 1). Every such
  row, logged or un-ticked, says why, and asks nobody to convert: "Logged in pounds before the
  workout changed to kilograms. Ask whoever changed it to fix the load." Distance and count rows get
  the line and stay read-only. Plan: [fam-1-change-logged-unit.md](../plans/fam-1-change-logged-unit.md).
