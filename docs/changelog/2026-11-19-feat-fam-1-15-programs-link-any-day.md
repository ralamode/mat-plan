# An athlete on no program gets the Programs link on any day

FAM-1 step 15 (lane B): the day page's "Not on a program yet" notice links to Programs for a live
athlete on every day, past days included, not only today or later (maintainer, 2026-11-19). The
notice means the athlete has no program now, so the link helps from any day. An archived athlete
still gets no link.
