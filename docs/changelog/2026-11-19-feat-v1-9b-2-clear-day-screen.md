# Clear this day is on the day page, with Restore all

`V1-9b` B2-ii ([plan](../plans/v1-9b-delete-and-restore.md) § B2 as amended).

- **Clear this day…** at the foot of **today's** page opens a dialog that names what it hides (each
  workout's logged rows, bodyweight, practice, entries the page doesn't show) and when it can be put
  back. Type `delete` to arm **Clear day**; Enter moves to the button and never clears.
- After a clear, a **banner** above the program line says how many entries are hidden and until when,
  with **Restore all** for the newest clear (focus lands on it). Every restore outcome is said on one
  line that keeps focus: all back, some kept because the day has one in their place, none, or nothing
  left.
- A closed or archived day's clear is a sentence inside the page's one notice, never a second box.
- The privacy notice and data inventory describe Clear this day as built: today only, any member,
  Restore all while the day is today or yesterday, the workout's record and note kept.
