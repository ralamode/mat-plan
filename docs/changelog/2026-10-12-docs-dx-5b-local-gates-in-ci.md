- **2026-10-12** — **DX-5(b) is planned: `skills:check`, `guards:test` and `status:check` move into CI's `quality` job** ([plan](../plans/dx-5b-local-gates-in-ci.md)). A five-lens panel found three blockers in the draft. On pnpm 11, the first `pnpm run` in a fresh checkout silently performs a full install unless `verify-deps-before-run` is off. A re-run never sees a newly added PR label, and the repo's own skip labels were documented as if it did (PR #67). And a guard self-test would have written fake security refusals into every green run's job summary.
