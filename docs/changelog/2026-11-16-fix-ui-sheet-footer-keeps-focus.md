# A sheet's footer keeps focus when the phone keyboard opens or closes

The shared `Sheet` (`apps/web/components/ui/sheet.tsx`) rendered its footer in one of two places: inside the scrolling body when the keyboard leaves little room (compact), or pinned below it otherwise. Each switch unmounted the footer and mounted a copy, so a focused footer button lost focus to the page whenever the keyboard opened or closed. Lane B hit this in the item picker: a retry focuses Create, the keyboard closes, and focus drops. The footer is now one element in one place. Only the scroller changes: the body alone when pinned, or the body and footer together under compact. Layout is unchanged. There's a new test for focus surviving a flip, and both changed tests fail on the previous component.
