# Two-Week S&C Program (green / no-practice baseline)

This is two weeks of the **Kids S&C 5-day split** (3 strength + 2 conditioning, + optional Sat, rest Sun), written for the **best-case day: kids rested, good mood, no club practice** — so every session runs full and the hard conditioning lands where it belongs.

Each day also has an **"If 2-hr evening practice instead"** row. That's the swap logic if the same calendar day actually has a hard evening practice on it — because a 2-hour practice is itself a hard skill + conditioning session and you must not pre-fatigue the legs before it.

## What "the full day" looks like

The strength/conditioning session in the two-week tables below is **only one block of the day.** Every day — 7 days a week, whether it's a lift day, a conditioning day, a rest day, or a practice day — the kids run the **"brushing the teeth" routine** (fundamentals + mobility + splits + mindset) around it. Full daily shape:

| Slot                   | What                                                                                                                                          | When                                                             |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| **On wake**            | **Rice bucket** — 6-min grip/wrist follow-along (Block 0)                                                                                     | First thing, before screens                                      |
| **Morning / midday**   | **Brush-the-teeth blocks 1–8** (stance, ladder, bridge, gymnastics+stretch, pressure, reaction, shots, drill-your-moves, splits) — ~30–40 min | Morning or midday; **splits never within 60–90 min of practice** |
| **Main slot**          | **The day's S&C session** (the two-week tables below)                                                                                         | No-practice day → any time; place the hard conditioning here     |
| **Evening (optional)** | **Nightly work** — mobility flow + gap-fillers, gated by fatigue and the "hard never doubles up" cap                                          | After dinner, submaximal                                         |
| **Lights-out**         | **Block 9 — the Brain Rep** (~2–3 min mindset)                                                                                                | In bed                                                           |

Full detail on every one of these is in the **appendices** at the bottom of this file (A: brush-the-teeth blocks 0–9 · B: 14-day gymnastics rotation · C: weekday stretch add-ons · D: nightly-work menu + caps). Everything here is self-contained — no dependency on the source repo.

## The 5 rules this program runs on

1. **Push the safe vectors hard, cap the two dangerous ones.** Heavy progressive strength (squat, hinge, press, weighted pull, carries) + hard low-impact conditioning are safe and high-value. The only capped vectors: **high-impact plyo volume** (jumps stay fresh + low-rep, ~10–20 quality contacts, throws-only on any knee/heel ache) and **grinding spinal lifts to failure** (leave 1–3 in the tank; bodyweight moves can go to failure — a missed pull-up is harmless).
2. **RAMP warm-up every session** (~8 min): **R**aise (light cardio) → **A**ctivate/**M**obilise (glutes, hips, ankles, T-spine — hurdle over/unders + duck-unders are gold) → **P**otentiate (a few explosive reps / ramp sets into the first lift). On jump days the jumps double as the potentiate.
3. **Progress week to week by the knob order:** add reps in range → add load (2.5–5 lb) once all sets are clean → add a set → tighten rest. Add load before chasing reps once form is grooved. **Week 2 below = a small bump on Week 1**, nothing more.
4. **Max 2 hard conditioning sessions per week** (live wrestling counts as hard). On a no-practice week, Tue + Thu are those two. On a practice day, **practice IS one of the two** — so you drop that day's separate hard intervals.
5. **Autoregulate per kid.** This program assumes green. If a kid shows up yellow (sore/poor sleep/sluggish): halve the power volume, drop the heaviest accessory, ease conditioning to steady-state. Red (pain/illness): mobility + light skill only.

> **Loads below** are carried from the source block's numbers as a starting point. **Confirm against each kid's last logged working set** and adjust — a load that runs clean for all sets is too light; reps that get ugly means drop it.

# APPENDICES — the full daily programming (runs every day, both weeks)

These run **every day of both weeks**, wrapped around whichever S&C session is scheduled. They don't change week-to-week (except splits, which just accumulates range). The evening-practice adjustment for each is called out inline.

## Appendix A — "Brushing the Teeth" daily routine (blocks 0–9)

Done every day like brushing your teeth: short, consistent, no drama. ~30–40 min for blocks 1–8, + ~2–3 min at bedtime for block 9. Goal is **habit and reps, not exhaustion.** Order of blocks 1–8 is flexible; Block 0 is fixed at morning wake, Block 9 at lights-out. Same routine for both kids **except Block 8 emphasis** (per-kid, noted below).

### 0. Morning grip — rice bucket _(on wake, daily — the wake-up anchor)_

A **6-minute rice-bucket follow-along** for grip / wrist / forearm strength, first thing, before screens. Hands into a deep bucket of rice, ~30–45 s each, continuous:

- **Squeeze & release** — open wide against the rice, then crush a fistful.
- **Bury** — dig both hands to the wrists.
- **Wrist curls** — palms up dig-and-lift (flexion); flip palms down, lift (extension).
- **Twists** — grab a fistful, rotate palm-up ↔ palm-down ("open the jar").
- **Stir** — big circles clockwise, then counter.
- **Finger spreads** — open all five fingers wide against the rice.
- **Claw grabs** — grab, lift, release, fast.

High transfer to hand-fighting, ties, mat control; wrist durability protects the joint in scrambles. Cue: _"Wake up, wrists first."_ Follow-along: https://www.youtube.com/watch?v=iVum3vWlh4Q

### 1. Stance holds

Good stance: knees bent, elbows in, hands up, head up. Build to 3 min total (e.g. 3×1 min). Add small motion (in-out, circle) once solid. Cue: _"Bend your knees, hands up, head up."_

### 2. Footwork / ladder

Agility-ladder + footwork (in-in-out, lateral, hops) — the ABCs (agility, balance, coordination, speed). 3–5 sets. Optional add: pogo jumps, single-leg balance.

### 3. Bridging

Back bridges + front (neck) bridges — strengthens neck and spine, protects in pin defense. Start low/controlled: ~10 reps or 2×30 s holds. Cue: _"Push through your feet, off your back."_

### 4. Gymnastics / mobility

The day's **rotating ~5-item, ~5-min set** from the **14-day rotation** (Appendix B) — same set both kids, a different mix each day to cover the full movement vocabulary. Low-impact **skill** work — _not_ conditioning, _not_ a finisher. Neck is **not** here (it's Block 3). **Plus** the weekday stretching (Appendix C).

### 5. Pressure game

Live-ish push/pressure with a partner (or wall/band): stay in stance, win position, don't get moved. A few short rounds. Cue: _"Be first. Don't get moved."_

### 6. Reaction game

React to a cue (hand touch, snap, level change) with the right response — snap-down, re-tie, sprawl. Trains reads, not memorized moves. Score /10.

### 7. Shot reps _(toward the 10,000-shot goal)_

Clean penetration-step / shot reps (solo shadow or on a partner/dummy). Quality over speed; every rep banks toward the cumulative 10K goal. Cue: _"Change levels, deep step, head up, drive the hips."_

### Drill your moves — daily skill round (≥1 × 1:30)

Beyond solo shots: pick a **go-to move or the week's focus** and drill it for **at least one continuous 1:30 round** (partner, dummy, or shadow). Builds the ability to keep attacking for a full period. Cue: _"Same move, chain it, keep hunting — a full period's worth."_ Rotate the move as it locks in.

### 8. Flexibility / splits _(~12 min)_

Flexibility window matters most at this age and gains are durable. **PNF (contract–relax)** is the lever: inside each hold, contract the stretched muscle into the floor 5 s, relax 10 s, sink deeper — 2–3 cycles per hold. Do in **morning/midday, never within 60–90 min of practice** (static stretch suppresses power).

- **Front split — 3 min each side (6 min)** — front leg straight, rear leg back, hips square. PNF the front-leg hamstring + rear hip flexor.
- **Middle split — 3 min** — legs wide, knees/toes up, slight forward lean. PNF the adductors.
- **Couch stretch — 60 s each side (2 min)** — rear shin against wall/couch, front foot flat in a lunge, tall torso. Biggest single unlock for the front split _and_ transfers to penetration-step depth. Front knee stays behind toes; glutes squeezed to protect the low back.
- **Pancake — 90 s** — sit in the middle split, fold forward, back flat (no rounding). Reach the spine long; don't force the chest down.
- _Optional accents (not daily — load creep):_ frog 60 s on light days; pigeon 30 s/side after wrestling-heavy days.

**Per-kid emphasis:**

- **Liam → hamstrings.** Spend the extra PNF cycles on the front-split front-leg hamstring + the pancake/forward-fold. Tight hamstrings are his limiter and they gate the Nordic curl + v-sit compression. If time's short, the hamstring holds are non-negotiable.
- **Scarlett → front & side (middle) splits.** Prioritize the front split (both sides) + the middle/side split; the pancake feeds the middle. If time's short, the front + side holds are non-negotiable.

### 9. The Brain Rep — bedtime mindset (~2–3 min, lights-out)

1. **30 s — Breath.** 2 physiological sighs (double-inhale nose, long exhale mouth) + 3 cycles of 4-in / 6-out.
2. **60 s — Highlight tape.** Walk through ONE wrestling scenario the way they want it — hand-fight from the whistle → inside tie → score. End on the score. **Never replay a loss here.**
3. **30 s — Identity line.** Out loud or in head: _"I am a wrestler who \____."_ Same line for a month at a time.
4. **30 s — Three to the bank.** Three things they did well today. Even after losses — the bank only goes one direction.

Cue: _"Breath, tape, line, bank — then sleep."_ (Pre-match and post-loss variants exist for tournament days and after hard losses.)

**Household vocabulary that surrounds the Brain Rep** (never lectured — one-word reflexes): _"Add the 'yet.'"_ · _"Effort / Attitude / Aggression"_ (said quietly in the warm-up area) · _"Almost-got-it, fix-it, try-again"_ (drill-zone self-locator) · _"Chop wood, carry water"_ · _"Bamboo week"_ (for plateaus) · _"40% — you've got more than you think"_ (**in-match only, said by the kid to themselves — never by the parent at the kid**).
**Parent-side rules:** same person leaving the gym (same face/hug/first-sentence win or lose) · first sentence is about effort never score ("I loved watching you out there") · _"Tell me one thing you tried"_ replaces "did you win?" · 30-min silence window before any technical talk post-match · no profile-stalking 24 hrs out · _"It's their journey, I'm honored to be along for the ride."_

### 🥋 Brush-the-teeth on a 2-hr evening-practice day

- **Rice bucket (0), stance (1), ladder (2), bridge (3), gymnastics (4), reaction (6), shots (7), drill-your-moves** — all fine, keep them (do them in the morning/midday).
- **Splits (8) — do it in the MORNING**, never in the 60–90 min before practice (static stretch suppresses power for the mat). If the only window is close to practice, skip splits that day rather than stretch cold-before-competition.
- **Pressure game (5)** — light or skip; practice will have plenty of live pressure.
- **Brain Rep (9)** — unchanged (bedtime). Use the **pre-match variant** on tournament days.

## Appendix C — Weekday stretching (part of Block 4, separate from the gymnastics rotation)

The **[15-Minute Stretching Routine for Fighters & Martial Artists](https://www.youtube.com/watch?v=UiO3WBOxUsc)** follow-along **+ these 3 adds** (hip rotation + thoracic extension — the ranges the video under-covers, and the ones that most protect knees and deepen shots):

- **Kneeling Thoracic Extension** — kneel, sit back toward heels, forearms on a bench/floor out front, **arch the UPPER back** (chest sinks between the arms). Keep the low back neutral — don't hinge into the lumbar. Opens the t-spine for overhead position + bridging.
- **Squat Internal Rotation** — in a deep bodyweight squat (or half-kneeling), drop one knee inward toward the floor and back, then the other — rotating the thigh **inward** at the hip. Slow, own the range. Hip internal rotation is the commonly-missing, knee-protective direction.
- **Hip 90/90** ([demo](https://www.rehabhero.ca/exercise/9090-rotation)) — sit both knees bent 90°, front shin across in front (external rotation), rear shin out to the side (internal). **Switch sides slowly without the hands**, staying tall. Trains both hip rotations with control — the exact angles the bottom of a squat and a scramble demand.

## Appendix D — Nightly work menu (optional, fatigue-gated)

The complementary work that sits _around_ the lift/conditioning days — designed to **add quality without adding fatigue.** Both kids already lift + live wrestle a full plate, so _if in doubt, do less._

**The one rule: hard never doubles up.** Live wrestling and the "Machine Gun" (tabata) circuits are the only two "hard" ingredients — never run both the same day, and never stack a hard conditioning night before a hard lift day or a competition. Everything else (mobility, grease-the-groove, steady-state) is restorative gap-fill, submaximal, never to failure.

**Assign the night by what else happened that day:**

| Night type                                | What to run                                                                                                                                                                             |
| ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Club / live wrestle night**             | Wrestling _is_ the conditioning. Add only: **Mobility Flow (5 min) + light Neck.** Nothing else.                                                                                        |
| **Lift day (the two-week strength days)** | The lift is the work. Add only: **Grease-the-Groove** (easy pulls/push) + a **Core Battery** + **Mobility Flow.** Skip GtG pulls on the Friday posterior day (already a hard pull day). |
| **Open night**                            | 🔴 **Machine Gun circuit** _or_ **Steady-State** — coach's call by how fatigued they look.                                                                                              |
| **Light / restorative night**             | Full **Mobility Flow + Grease-the-Groove + Grip.** Easy on purpose.                                                                                                                     |
| **Full rest (≥1×/week)**                  | Sleep, food, hydration. No training.                                                                                                                                                    |

**Weekly caps:** Machine Gun/tabata **≤2 nights** (drop to 1 or 0 on a tournament week) · **≥1 full rest day** (ideally a 2nd very light day) · **sleep 9–10 hr** (the #1 recovery tool). **Back-off flags → mobility only:** unusual fatigue, getting sick often, cranky/flat mood, dreading practice, sleep going sideways.

**The menus the night draws from:**

- **Grease-the-Groove** (frequency without fatigue — 3–5 easy sets across the evening, ~40–60% of max reps, always 2–3 short of failure): **Pull ladder** (rows → band pull-up → strict pull-up → tempo chins → weighted-vest → chest-to-bar → muscle-up, earned last) · **Push ladder** (incline → strict → unstable → weighted → ring → dips) · **Legs/balance** (BOSU squat, box-assisted pistol progression, single-leg RDL, split-squat isohold).
- **Grip** (near-daily OK): rice bucket · rope climb · farmer carry · dead hang · towel pull-up hang · plate pinch carries.
- **Core Battery** (pick 3–4, ~3 rounds): _anti-rotation_ (Pallof, landmine 180s, single-leg-lift plank, suitcase carry) · _flexion_ (hanging leg raises, ab-wheel, hollow rocks/V-ups, reverse crunch) · _extension_ (back/hip extensions, Superman holds) · _neck — LIGHT_ (controlled nods + slow rotations, partner-resisted isometrics 10 s; **no heavy loaded bridging for kids**).
- **Mobility Flow (~8–10 min):** cat-cow ×8 · world's-greatest ×3/side · 90/90 hip switches ×10 · couch stretch 45 s/side · open-book ×8/side · shoulder CARs ×5/side · ankle rocks ×10/side · deep squat sit 60 s · 4-in/6-out breathing ×8 (signals "sleep").
- **Steady-State** (recovery engine, nasal pace): 20–35 min easy bike · 1.5–2.5 mi easy jog · or 20 min easy row.

### 🥋 Nightly work on a 2-hr evening-practice day

The practice **is** the night's hard work → it's a **"club night."** Add **only Mobility Flow (5 min) + light Neck** afterward as a cool-down. **No** Machine Gun, **no** hard grease-the-groove, **no** steady-state on top — that would double the hard. Grip (rice bucket) is fine if they want it; it's low-fatigue. Then straight to the Brain Rep + sleep.

## One-line summary of the practice-day logic (for whoever reads this next)

On a **2-hr evening-practice day**, do three things: (1) **move any heavy leg or spinal lift** (squat, trap-bar, RDL) to a **morning slot with a 4–6 h gap and +1 RIR**, or off the day entirely — never fresh legs traded for the mat; (2) **delete that day's separate hard conditioning** — the practice is one of your two hard sessions for the week; (3) **keep only what layers safely near the mat** — prehab (neck, hips, grip, balance), mobility, and light upper-body pulls/presses. Brush-the-teeth stays, minus the flexibility/splits block within 60–90 min of practice.
