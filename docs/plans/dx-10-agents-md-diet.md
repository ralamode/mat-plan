# DX-10 — AGENTS.md on a diet: rules stay, stories move

> Backlog: [plan.md](../plan.md) row DX-10. Branch: `docs/dx-10-agents-md-diet`.

## Goal

`AGENTS.md` is the one contract every session and every subagent loads before its first prompt
(`CLAUDE.md` and `apps/web/CLAUDE.md` are both `@AGENTS.md`). It is 6,565 words (45 KB, roughly 11k
tokens), and about a third of that is no longer rule but record: the TEN-2b six-second race, PR
numbers, three "verified via the API, 2026-09-30" stamps, three separate Neon-branch caveats, and
paragraphs that restate `docs/lessons.md`, `docs/tech-debt.md`, `docs/plans/README.md`,
`docs/features/README.md`, the PR template and the skills. The skills index already notes that each
panel spawn pays for the file again (`.claude/skills/README.md:73-76`). This PR cuts the file by
about 40% **without removing a rule**: every deleted sentence is a story that already has a home, a
duplicate within the file, or a restatement of a document the file points at. The file's own rules
license this: "keep the rules here (DRY)" (`AGENTS.md:5`), "other docs point here rather than
restating it" (`:371`), "duplicated prose goes stale first" (`:352`).

## Alternatives considered

- **Nested `CLAUDE.md` per package** (`packages/db/CLAUDE.md` holding the schema + migration rules,
  `apps/web/CLAUDE.md` holding server + UI rules, root keeping the cross-cutting ones). This is the
  on-demand mechanism Claude Code actually has, and the repo already uses the nested file
  (`apps/web/CLAUDE.md` is `@AGENTS.md`). Rejected **for now** because: a plan author or panel reviewer
  needs the DB rules before any DB file is opened (panels run before implementation); nested-file
  loading for Agent-tool subagents is less documented than root loading; and it changes the
  `apps/web/CLAUDE.md` precedent. It is the concrete next step if the file regrows past the budget.
- **Delete the stories outright, no pointers.** Rejected: a rule with no reachable "why" is the first
  one a future session argues away, and two files rely on a visible unwired-gate warning.
- **A hard word-budget gate in `verify`/CI.** Deferred: the advisory line in `hold-the-bar` prints the
  number at the moment regrowth happens; a failing gate is earned on the first observed regrowth. No
  backlog row is opened for it.

## Risks / rollback

- **A rule line is swept into a trim range.** The ranges are now exact block boundaries and each row
  names the adjacent rule lines it leaves alone; `hold-the-bar` flags the file regardless.
- **A citation is orphaned.** The probe above reads the whole tree, joins wrapped lines, and accepts
  the link and unquoted forms. The two orphans it found are fixed in this PR.
- **Merge friction.** `AGENTS.md` had 20 commits in 30 days. Ship quickly; merge `main` in before
  merging, never rebase once pushed.
- **Rollback:** docs plus a two-line advisory print; revert the squash commit.

  ("the e2e needs a real Postgres; when Docker isn't available…"), which contradicts `pnpm e2e:local`.
  Stale, pre-existing, not this PR's thesis; listed here so they are found.
- **The other oversized docs** (`plan.md` 392 KB, `status.md` 126 KB, `runbooks.md` 101 KB). Different

- **Rewriting any rule.** This PR changes how long the file is, never what it requires, with the one
